# 🔗 Encurtador de URL com Interface Tkinter

Este é um pequeno aplicativo desktop feito em Python com `Tkinter` para encurtar URLs usando o serviço **TinyURL** via a biblioteca `pyshorteners`.

---

## 📦 Requisitos

- Python 3.x
- pip (gerenciador de pacotes do Python)

---
