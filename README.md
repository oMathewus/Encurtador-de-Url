# 🔗 Encurtador de URL com Tkinter | URL Shortener with Tkinter

Este é um pequeno aplicativo desktop feito em Python com `Tkinter` para encurtar URLs usando o serviço **TinyURL** via a biblioteca `pyshorteners`.

This is a small desktop application built with Python and `Tkinter` to shorten URLs using the **TinyURL** service via the `pyshorteners` library.

---

## 📦 Requisitos | Requirements

- Python 3.x  
- pip (gerenciador de pacotes | package manager)
